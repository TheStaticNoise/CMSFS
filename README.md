# CMSFS
**CMSFS** (Chestnut Monitoring System Fucking Sucks) is an Arduino-based project developed for a school science fair. Its purpose is to monitor environmental conditions relevant to chestnut growth by collecting temperature, humidity, and soil moisture data.

## Requirements

### Hardware
- Arduino Uno (any compatible revision)
- DHT22 temperature and humidity sensor
- Generic resistive soil moisture sensor
- 16×2 LCD display (non-I2C)
- 10 kΩ potentiometer (LCD contrast)
- Push button
- Assorted resistors
- Breadboard and jumper wires
